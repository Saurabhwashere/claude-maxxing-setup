# Weekly report

## Inputs
- My raw notes (bullet points, voice-dump transcript, or messy text).
- Optional: the client or team name.

## Steps
1. Read `references/template.md` for the layout. If it doesn't exist, use the layout below.
2. Pull out three things from my notes: wins, what's next, and anything blocked.
3. Turn each into one plain sentence. Use numbers wherever my notes have them.
4. Keep the whole update under 200 words.
5. End with one clear ask if something is blocked. Otherwise no ask.

## Layout
```
Hi <name>,

This week
- <win 1>
- <win 2>

Next week
- <plan 1>
- <plan 2>

Need from you
- <ask, or remove this section>

<my sign-off>
```

## Rules
- Write in my voice from CLAUDE.md.
- No filler openers like "I hope this finds you well".
- If my notes don't say something, don't invent it. Ask me instead.

## Make it yours
Add `references/template.md` with a real past update you liked, and `references/client-list.md` with names and how formal each one likes it.
